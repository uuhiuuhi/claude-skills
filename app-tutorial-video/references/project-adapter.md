# 프로젝트 어댑터 — 프로젝트가 채울 것

스킬은 범용이고, 아래는 **프로젝트 저장소 안에** 둔다(범용 저장소에 회사·사람 이름 · 주소 · 프로젝트 식별자 · 계정 접두사를 넣지 않는다).

| 항목 | 무엇 | 예시 꼴 |
|---|---|---|
| 개발 환경 판정 | 지금 주소·DB 가 시험 환경인지 판정하는 함수 하나 | 허용 목록(로컬 주소 · 개발 프로젝트 식별자)에 없으면 거부 |
| 로그인 | 역할 이름 → 시험 계정으로 로그인하는 함수 | 비공개 설정 파일에서 읽기 · 값 출력 금지 |
| 화면 표·라벨 원천 | 대본 작성기가 쓸 화면 목록과 도움말 문구 | 앱의 화면 경로표 · 도움말 원본 파일 |
| 외부 발송 대상 | 녹화 전에 꺼짐을 실측할 것들 | 예약 발송 잡(이름 + 실제 호출 함수) · 메신저 연결 주소 표 |
| 저장성 낱말 | 저장으로 볼 단추 글자 목록 | 저장 · 등록 · 발행 · 삭제 · 전송 |
| 시연 표식 | 시연으로 만든 기록을 알아볼 앞머리 | `[영상 촬영]` |
| TTS | 주 엔진 · 대체 엔진 · 목소리 · 언어 | 무료 온라인 음성 → 운영체제 기본 음성 |
| 쉬운 말 검사 | 해설 문장에 금지할 낱말 목록 | 개발 용어 목록 |
| 길이 상한 | 영상 길이·파일 크기 | 3분 · 50 MB 경고 |
| 올리기(선택) | 결과를 사용자에게 보이는 곳 | 비공개 보관함 + 로그인 사용자 서명 주소 |

## 설치 순서(새 프로젝트)
1. 이미 있는 화면 촬영 도구(설명서 생성기·화면 검사 도구)가 있으면 **로그인·환경 판정·서버 띄우기를 공용 함수로 꺼내 재사용**한다(복사 금지).
2. 손으로 쓴 대본 3~6편으로 영상 품질부터 증명한다.
3. 그 뒤에 대본 자동 작성(제목 → 대본) → 의뢰 화면 → 무인 실행기 순서로 붙인다(뒤로 갈수록 되돌리기 어렵다).
