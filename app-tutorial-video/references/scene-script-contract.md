# 장면 대본 계약 (version 1)

대본 하나 = 영상 하나. 사람이 손으로 쓰든 AI 가 쓰든 **같은 형식**이고, 형식 검사기를 통과해야 녹화한다.

```json
{
  "version": 1,
  "title": "장애 접수하는 법",
  "scenes": [
    {
      "role": "staff",
      "path": "/tickets",
      "narration": "왼쪽 메뉴에서 「티켓 접수」를 누릅니다.",
      "actions": [
        { "do": "highlight", "target": "티켓 접수" },
        { "do": "click", "target": "티켓 접수" },
        { "do": "wait", "target": "고객사" }
      ]
    },
    {
      "role": "staff",
      "narration": "고객사를 고르고 증상을 한 줄로 적습니다.",
      "actions": [
        { "do": "fill", "target": "증상", "value": "프린터가 인쇄되지 않음" }
      ]
    }
  ]
}
```

## 필드
| 필드 | 필수 | 뜻 |
|---|---|---|
| `version` | ✓ | 계약 판. 모르는 판이면 거부 |
| `title` | ✓ | 영상 제목 = 출력 폴더 이름. 경로에 못 쓰는 글자(`\ / : * ? " < > \|` · `..`) 금지 |
| `scenes[].role` | ✓ | 어느 시험 계정으로 보는가(프로젝트 어댑터의 역할 이름) |
| `scenes[].path` | 첫 장면만 ✓ | 이동할 화면. **생략 = 앞 장면의 화면 그대로**(목록 → 상세처럼 이어지는 흐름을 잃지 않는다) |
| `scenes[].narration` | ✓ | 해설 문장. 쉬운 말 검사 통과 필수 |
| `actions[].do` | ✓ | `click` · `fill` · `wait` · `highlight` 넷뿐 |
| `actions[].target` | ✓ | **화면에 보이는 글자**(접근성 이름·라벨). CSS 선택자·좌표 금지 — 화면이 바뀌어도 대본이 덜 낡는다 |
| `actions[].value` | `fill` 만 | 입력할 글자. 개인정보·실제 고객 정보 금지 |

## 검사 규칙(범용)
1. 알 수 없는 키 = 오류(오타가 조용히 무시되지 않게). 한 동작에 잘못된 `do` 가 있어도 같은 동작의 다른 키 진단을 숨기지 않는다.
2. `target` 은 리허설에서 **정확히 하나**만 찾아져야 한다(0개 = 없음 · 2개 이상 = 모호함 — 둘 다 실패).
3. 저장성 동작(저장·등록·발행·삭제·전송 류 단추의 `click`)은 프로젝트가 허용한 경우에만, 그리고 시연 표식이 붙은 입력이 **같은 장면 안에** 있을 때만 허용한다(표식 승인은 장면마다 초기화).
4. `click` 뒤 화면이 바뀌면 다음 동작은 바뀐 화면에서 기다릴 글자를 `wait` 로 적는 것을 권장한다(엉뚱한 화면으로 넘어간 채 녹화되는 것 방지).
5. 서사 순서 권장: 첫 장면 = 메뉴 위치 · 가운데 = 맥락 → 동작 · 마지막 장면 = 결과 화면 설명.
