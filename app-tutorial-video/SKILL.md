# app-tutorial-video (v0.1 · 지침·계약)

**한 줄**: 장면 대본(JSON) 하나로 「실제 화면 조작 녹화 + 음성 해설 + 자막」 영상을 같은 방식으로 반복 생산한다. 이 스킬은 **순서·계약·진단 원칙**을 준다. 실제 동작은 프로젝트 저장소 안의 버전 관리되는 도구가 맡는다(스킬에 코드를 두지 않는다).

## 언제 쓰나
- 「제목을 적으면 소개 영상이 만들어지는」 기능을 새로 설계하거나, 이미 있는 제작 도구를 점검할 때.
- 한 편을 손으로 만들어 보고 싶을 때(대본을 쓰고 5단계를 직접 돈다).

## 절대 규칙
1. **운영 주소에서 녹화하지 않는다** — 개발·시험 환경 판정은 프로젝트 어댑터의 함수 하나가 하고, 아니면 **브라우저를 띄우기 전에** 멈춘다.
2. **AI·사람이 비밀번호를 치지 않는다** — 로그인은 스크립트가 프로젝트의 비공개 설정 파일에서 시험 계정을 읽는다. 계정 값은 로그·자막·파일 이름·장면 기록 어디에도 남기지 않는다.
3. **「확인 못 함」은 「꺼짐」이 아니다** — 외부 발송(메신저·메일·푸시) 꺼짐을 실측하지 못하면(권한 오류 · 조회 0행 · 열 없음) 녹화하지 않는다. 조회 대상은 이름과 실제 호출 함수 **둘 다**로 찾는다.
4. **실패는 이름 있는 오류로** — 「n번째 장면: 「저장」 단추를 못 찾음」처럼 사용자가 읽을 수 있는 이유로 끝낸다. 경고를 내고 계속 진행해 반쯤 깨진 영상을 내지 않는다.
5. **외부 공개 전 사람 확인** — 자동으로 만든 영상은 「확인 대기」로 두고 사람이 공개한다(틀린 순서를 가르치는 영상 방지).

## 5단계
1. **탐색(Discover)** — 대상 화면을 실제로 열어 라벨·입력 칸 종류·선택지·필수 표시를 모은다. 대본은 이 목록에 있는 글자만 쓴다(없는 단추를 지어내지 않는다).
2. **리허설(Rehearse = 사전 걸음)** — 녹화 없이 대본의 모든 단계를 밟아 대상이 **정확히 하나** 찾아지는지 확인한다. 실패하면 1회 고쳐 쓰고, 그래도 실패면 이유를 남기고 끝.
3. **녹화(Record)** — `recordVideo`(1280×720) · 장면 경계 시각 기록 · 시작 시각은 **페이지를 만든 뒤** 잰다 · 화면 이동마다 커서 다시 심기 · 대상은 화면 안으로 스크롤한 뒤 강조·클릭 · 연출 속도 기본값(아래).
4. **음성(TTS)** — 함수 하나로 감싼다: 주 엔진 → 실패 시 대체 엔진 → 둘 다 실패면 이름 있는 실패. 해설 문장은 프로젝트의 쉬운 말 검사를 통과해야 진행.
5. **조립(Assemble)** — 녹화 실제 길이를 ffprobe 로 재어 장면 경계를 그 안으로 자른다 → 장면별 자르기 → 영상이 짧으면 마지막 화면 늘리기(tpad) / 음성이 짧으면 무음 채우기(apad) → 이어 붙이기 → mp4(H.264) + srt. 자막은 굽지 않고 트랙 + srt 파일(글꼴 경로 문제 회피).

## 연출 속도 기본값
입력 글자당 30ms · 화면 이동 뒤 1초 · 누르기 뒤 0.5~2초 · 마지막 장면 끝 2초 · 스크롤 뒤 300ms. 고정 대기가 화면 준비 확인을 대신하지 않는다(기다릴 글자가 있으면 그것을 기다린다).

## 안전 훅 순서 (바꾸지 않는다)
운영 주소 거부 → 도구 부품 사전검사(ffmpeg · 녹화 부품 · TTS) + 외부 프로세스 시한 → 외부 발송 꺼짐 실측 → 로그인 → 리허설 → 녹화. 자세히 = `references/safety-hooks.md`.

## 무인 자동화로 확장할 때 (선택)
화면 메뉴는 이 도구를 직접 실행하지 못한다(웹 서버 안에서 녹화·조립이 돌지 않는다). **의뢰 표 + 상시 켜진 PC 의 예약 작업 + 좁은 전용 서버 창구(다음 의뢰 잡기 · 결과 올리기 두 동작만)** 로 잇고, 관리자 열쇠를 그 PC 에 두지 않는다. 한 번에 1건 · 하루 상한 · 오래 「제작 중」이면 되돌리기 · 올리기 전 길이·크기·장면 수 실측.

## 하지 않는 것
자막 굽기 · 동작별 음성 동기(장면 단위로 시작한다) · 팝업 별도 녹화(필요할 때 후속) · 저장 결과를 영상 성공 조건으로 쓰기(안내형 대본이 기본) · 운영 데이터 녹화.
